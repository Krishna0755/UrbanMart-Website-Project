# 📱 Urban Tech Store

A modern, responsive e-commerce application for premium gadgets.

## 🛠 Technologies Used

- **Frontend:** React.js
- **Styling:** Custom CSS (Responsive Design)
- **Routing:** React Router
- **State Management:** React Context (Cart)
- **Environment:** Node.js + Vite

## 🌟 Key Features

- **Responsive Design:** Optimized for all screen sizes from mobile to desktop
- **Hero Section:** Premium landing with TechConnect logo and CTAs
- **Product Search:** Live search with dropdown across all categories
- **Category Pages:** Browse Phones, Laptops, and Tablets
- **Shopping Cart:** Add/remove items, quantity management, checkout
- **Product Cards:** Interactive cards with cart status indicators

## 🚀 Getting Started

1. Clone the repo: `git clone https://github.com/Krishna0755/Urban-Tech-Store-Project.git`
2. Install dependencies: `npm install`
3. Run locally: `npm run dev`

## 📱 Responsive Breakpoints

- **Desktop:** Default layout with full navigation
- **Tablet (≤768px):** Hamburger menu, adjusted spacing
- **Mobile (≤480px):** Compact layout, vertical cart items
- **Small Mobile (≤360px):** Optimized for very small screens

## 🛒 Shopping Features

- Search products by name or category
- Add items to cart with visual feedback
- Manage quantities in cart
- Persistent cart using localStorage
- Category-based product filtering
